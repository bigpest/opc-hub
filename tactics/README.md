# Tactics

Things one person can actually execute, without hiring. One file per tactic.

Naming: lowercase, hyphen-separated, descriptive — `pricing.md`, `validation.md`, `burnout.md`.

Each tactic follows the structure in [CONTRIBUTING.md](../CONTRIBUTING.md#tactic-and-playbook-submissions): problem, audience, steps, time and money, pitfalls, evidence.
