# Stories

First-hand accounts from people building one-person companies. One file per story.

Naming: `story-<number>-<short-slug>.md`, e.g. `story-001-my-first-opc-fail.md`.

Each story follows the structure in [CONTRIBUTING.md](../CONTRIBUTING.md#story-submissions): starting point, what you tried, what it cost, outcome, what you would tell someone starting today.
